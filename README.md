# Managing my dotfiles

I use [chezmoi](https://www.chezmoi.io) and it works pretty well so far. Don't
look at my files for best practices, though. You can find many better, more
organized examples with a simple search of your favorite source code
repository.

## QRG

Add a dotfile to chezmoi's management: `chezmoi add`

Edit a dotfile that's managed by chezmoi: `chezmoi edit`

Commit and push changes: `chezmoi push`

Pull and apply changes: `chezmoi update`
